# Question 5: Describe the methods used for the quality assessment of the fitted microeconometric models.

## Answer

Quality assessment of microeconometric models involves multiple diagnostic approaches to evaluate model specification, parameter reliability, and predictive performance. Goodness-of-fit measures include R-squared for linear models and pseudo-R² (McFadden, Cox-Snell, Nagelkerke) for discrete choice models, though these should be interpreted cautiously as they differ from traditional R-squared. Information criteria such as Akaike Information Criterion (AIC) and Bayesian Information Criterion (BIC) enable model comparison while penalising complexity, with lower values indicating better model performance. Statistical significance tests assess parameter reliability through t-tests, Wald tests, and likelihood ratio tests, while confidence intervals provide uncertainty quantification. Residual analysis examines model assumptions through plots of standardised residuals, leverage statistics, and influence measures to identify outliers and specification errors. Cross-validation techniques, including k-fold and leave-one-out methods, assess out-of-sample predictive performance and help detect overfitting. For binary and multinomial models, classification accuracy metrics (sensitivity, specificity, precision, recall) and ROC curves evaluate prediction quality. These comprehensive assessment tools ensure robust model validation and reliable inference in microeconometric applications.
