## Answer

Dimensionality reduction condenses high-dimensional data into a smaller set of informative features, mitigating the curse of dimensionality and enhancing visualisation. Linear methods like Principal Component Analysis (PCA) rotate correlated financial ratios into orthogonal components that feed credit-risk models. Singular Value Decomposition underpins latent semantic indexing, mapping term–document matrices to topics for search engines. Non-linear techniques capture manifolds: t-SNE and UMAP project 784-pixel MNIST images into two-dimensional plots that reveal digit clusters; in genomics they expose cell subtypes in single-cell RNA-seq counts. Autoencoders compress sensor streams on edge devices, cutting bandwidth while preserving patterns for anomaly detection. Feature hashing reduces sparse text vectors before training logistic-regression classifiers at web scale. By discarding noise and redundancy, these methods speed up computation, improve generalisation, and enable humans to grasp structure that raw variables obscure.
